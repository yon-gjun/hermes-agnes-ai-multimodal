# Agnes AI 多模态套件 > **通过 Python 脚本配置和使用 Agnes AI 多模态模型（文本、图片、视频）** ## 概述 Agnes AI 由 Sapiens AI 开发，提供三个独立的模型，共用同一个 API Key 和 Base URL（`https://apihub.agnes-ai.com/v1`），但每个模型使用**完全不同的 API 端点**——**不可互换使用**。 ## 模型总览 | 模型 | 类型 | 端点 | Hermes 角色 | |------|------|------|------------| | `agnes-2.0-flash` | 文本对话 | `/v1/chat/completions` | Hermes 内置默认模型 | | `agnes-image-2.1-flash` | 图片生成 | `/v1/images/generations` | 专用 Python 脚本 | | `agnes-video-v2.0` | 视频生成 | `/v1/videos`（异步） | 专用 Python 脚本 | ## 快速开始 ### 1. 配置 API Key 在 `~/.hermes/.env` 中添加： ``` AGNES_API_KEY=sk-xxxx ``` ### 2. 配置 Hermes 默认模型 在 `config.yaml` 中设置： ```yaml model: api_key: sk-xxxx base_url: https://apihub.agnes-ai.com/v1 default: agnes-2.0-flash provider: custom ``` ### 3. 安装技能 ```bash hermes skill install agnes-ai-multimodal ``` ### 4. 使用示例 ```bash # 文生图 python ~/agnes_image_gen.py text "一家人在草原上野餐" # 文生视频（5秒） python ~/agnes_video_gen.py text "一家人在草原上放风筝" # 图生视频 python ~/agnes_video_gen.py image "图片URL" "提示词" ``` ## 关键踩坑
⚠️ 陷阱 1：图片和视频模型不能当作对话模型配置到 Hermes，否则 HTTP 404。 ⚠️ 陷阱 2：视频 API 返回的下载 URL 在 remixed_from_video_id 字段，不是 video_url。 ⚠️ 陷阱 3：视频帧数必须是 8n+1 格式。5秒→121帧，10秒→241帧。 ⚠️ 陷阱 4：图生视频请求超时。需要 timeout=60 以上。 ⚠️ 陷阱 5：永远不要在 Python 源码中硬编码 API Key。使用 read_key() 函数模式。

# Agnes AI Multimodal Suite > **Configure and use Agnes AI multimodal models (text, image, video) via Python scripts.** ## Overview Agnes AI (by Sapiens AI) provides three distinct models under one API key at `https://apihub.agnes-ai.com/v1`. Each model uses a **DIFFERENT endpoint** — they are **NOT interchangeable**. ## Models at a Glance | Model | Type | Endpoint | Hermes Role | |-------|------|----------|-------------| | `agnes-2.0-flash` | Text/Chat | `/v1/chat/completions` | Built-in default | | `agnes-image-2.1-flash` | Image Gen | `/v1/images/generations` | Python script | | `agnes-video-v2.0` | Video Gen | `/v1/videos` (async) | Python script | ## Quick Start ### 1. Set API Key Add to `~/.hermes/.env`: ``` AGNES_API_KEY=sk-xxxx ``` ### 2. Configure Hermes Default Model In `config.yaml`: ```yaml model: api_key: sk-xxxx base_url: https://apihub.agnes-ai.com/v1 default: agnes-2.0-flash provider: custom ``` ### 3. Install Skill ```bash hermes skill install agnes-ai-multimodal ``` ### 4. Usage Examples ```bash # Text to image python ~/agnes_image_gen.py text "family picnicking on grassland" # Text to video (5s) python ~/agnes_video_gen.py text "family flying kites on grassland" # Image to video python ~/agnes_video_gen.py image "image-url" "prompt" ``` ## Critical Pitfalls
⚠️ Pitfall 1: You CANNOT use image/video models as chat models. HTTP 404 if configured as default model. ⚠️ Pitfall 2: Video API returns download URL in remixed_from_video_id field, NOT video_url. ⚠️ Pitfall 3: Video frames must follow 8n+1 rule. 5s→121, 10s→241. ⚠️ Pitfall 4: Image-to-video needs timeout=60+ due to server-side image processing. ⚠️ Pitfall 5: Never hardcode API keys in Python. Always use read_key() function pattern.
